Architecture

Built from layers

A multilayer perceptron is just layers of neurons stacked on top of one another. Data enters through an input layer, passes through one or more hidden layers, and leaves through an output layer.

This one takes in two numbers — the coordinates of a point — and outputs a single probability: which of two classes that point belongs to.

Architecture

Every connection counts

Every line between neurons is a weight — a number the network will tune as it learns. Thicker, brighter lines carry more influence.

Teal connections push a neuron's value up; orange connections push it down. Each neuron also carries its own bias, a small nudge added regardless of input.

Right now these weights are random — the network hasn't learned anything yet.

Forward pass

Feed it an example

Let's send one real data point through the network: a single (x, y) coordinate from our dataset, with a known true class.

Those two numbers become the activations of the two input neurons — nothing more.

Forward pass

Weighted sums, layer by layer

z = w·x + b    a = f(z)

Each neuron multiplies every incoming value by its connection's weight, adds them all up, adds its bias to get z, then squashes z through an activation function f to get its output a.

Watch the signal ripple forward, layer by layer.

Forward pass

…and a prediction pops out

After passing through both hidden layers, the signal reaches the output neuron, which reports a single number between 0 and 1 — the network's confidence in class 1.

With random, untrained weights, don't expect this guess to be any good yet.

Activation functions

Why the bend matters

If every neuron just passed its weighted sum straight through, stacking layers would be pointless — any number of linear layers collapses into one big linear function.

An activation function bends that line, letting the network represent curved, complex boundaries. This network uses tanh in its hidden layers and sigmoid at the output, so its final answer always lands between 0 and 1.

Loss

Scoring the mistake

Now compare the prediction to the truth. A loss function turns that gap into a single number — small when the guess is close, large when it's confidently wrong.

L = −[y·log(ŷ) + (1−y)·log(1−ŷ)]

This is binary cross-entropy. The bigger the loss, the more the network needs to change.

Backpropagation

Backprop starts at the end

To fix the mistake, the network works backward. It starts with the error at the output neuron and asks: which weights pushed me in the wrong direction, and by how much?

This backward error signal is what gives back-propagation its name.

Backpropagation

The chain rule nudges every weight

w ← w − η · ∂L/∂w

Using the chain rule, the error signal flows backward through every layer, assigning each weight and bias a share of the blame — its gradient.

Every weight then takes one small step opposite its gradient, scaled by a learning rate η. Watch the connections shift.

Training over time

Now do that a thousand times

One update barely moves the needle. But repeat this forward pass → loss → backward pass → update cycle over every point in the dataset, again and again, and a decision boundary emerges.

This live network is training right now on a two-moons dataset it has never seen before. Watch the boundary bend to separate them, and the loss curve fall.

Recap

From random noise to a real boundary

That's the whole loop: weights and biases transform input into output; an activation function adds the bend needed for nonlinearity; a loss function scores the mistake; and backpropagation turns that score into thousands of tiny, coordinated corrections.

Every large neural network — image classifiers, language models, recommendation systems — runs on exactly this loop, just at a much bigger scale.

That's a multilayer perceptron.
